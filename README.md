# Home Assistant Configuration

This repository stores the Home Assistant configuration used on the local
network. It includes a basic set of integrations, example automations and
customisations, and a local voice assistant powered by the Wyoming protocol.

## Documentation

- [Integrations overview](docs/integrations.md)
- [Device and assistant setup](docs/device_setup.md)
- [Log Watcher integration](docs/logwatcher.md)
- Example YAML snippets are available in the [`examples/`](examples) directory.

## Utilities

- `scripts/device_scanner.py` – scan a network range for active hosts.
